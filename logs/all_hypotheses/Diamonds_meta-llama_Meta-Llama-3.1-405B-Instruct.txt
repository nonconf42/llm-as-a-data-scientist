2. Calculate the average price for each group.
3. Compare the average prices using a statistical test (e.g., t-test).
4. Assess the significance of the observed difference to confirm the hypothesis.
5. Use results to inform pricing strategies for diamonds with shallow depths.
'''
def test(dataset):
    import pandas as pd
    from scipy.stats import ttest_ind
    shallow_depth = dataset[dataset['depth'] < 60]
    deep_depth = dataset[dataset['depth'] > 60]
    result = ttest_ind(shallow_depth['price'], deep_depth['price'], alternative='greater').pvalue < 0.05
    return int(result)
